# Changelog

## 1.0.0 — 2026-09-28

- Claude Code weekly remaining percentage and local service icon in the menu bar.
- Separate five-hour balance and reset times in the menu.
- Five-minute polling, wake/manual refresh, and server rate-limit cooldown.
- Existing Claude Code login via Keychain/file fallback; expired authentication
  refresh delegated to the official CLI.
- Universal macOS 13+ build, Korean/English menus, per-user installer/uninstaller.
- No credentials or third-party artwork in release files.

Validated with Claude Code 2.1.116 on Apple Silicon/macOS 26.2. Builds are not
Apple-notarized; the internal usage endpoint may change.
